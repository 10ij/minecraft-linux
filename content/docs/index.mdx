# Minecraft Linux

The unofficial Minecraft Linux launcher runs the Android version of
Minecraft Bedrock Edition on Linux and macOS. It supports Minecraft builds
for `x86`, `x86_64`, `armhf`, and `arm64`.

The launcher uses a compatibility layer for Android's Bionic libc and
rewrites Android-specific services such as AppPlatform, Store, and Xbox Live
for desktop systems. It is not an emulator and does not provide Minecraft or
an APK.
